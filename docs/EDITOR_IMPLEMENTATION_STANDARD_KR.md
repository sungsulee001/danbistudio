# Danbi Studio 실제 편집기 구현 기준

> 문서 우선순위: 기능 완료 판정은 `EDITOR_COMPLETION_DEFINITION_KR.md`의 필수 조건과 완료 게이트를 우선한다. 외부 소스 복제/수정/참고 결정은 `THIRD_PARTY_SOURCE_REGISTER_KR.md`를 우선한다. 이 문서는 개별 기능 구현 시 지켜야 할 품질 기준이다.

## 원칙

목표는 기능 버튼이 많은 데모가 아니라 실제 편집을 시작할 수 있는 로컬 영상 편집기다. CapCut, Shotcut, Filmora의 콘텐츠, 라이선스, 내장 AI 모델은 제외하더라도 편집기의 기본 조작과 결과물 품질은 같은 기준으로 맞춘다.

## 완료 판정

기능 하나를 완료로 표시하려면 아래 항목을 모두 만족해야 한다.

1. UI에서 조작할 수 있다.
2. 실제 미디어 preview 또는 timeline 상태에 반영된다.
3. 렌더 대상 기능이면 FFmpeg 출력에도 반영된다.
4. 프로젝트 저장/불러오기 뒤에도 유지된다.
5. 코어 함수 또는 API 테스트가 있다.
6. 실패 상태와 경고가 사용자에게 보인다.
7. 기존 저장 프로젝트는 마이그레이션으로 새 기본값을 자동 보강한다.
8. 프로젝트 단위 이동이 필요한 기능은 SQLite와 별개로 파일 export/import 경로를 가진다.

하나라도 빠지면 구현 중 또는 껍데기 상태로 분류한다.

## 현재 우선순위

1. 실제 미디어 파이프라인
   - 업로드 파일 저장
   - `ffprobe` 기반 duration, resolution, FPS, codec 분석
   - thumbnail, waveform, proxy cache 생성
   - 누락된 asset source/renderPath를 기존 timeline clip 유지 상태로 relink
   - Media Health에서 missing renderPath, volatile source, cache gap, missing asset reference를 보여주고 복구 액션 제공

2. 타임라인 정확도
   - frame 단위 snap
   - ripple/roll/slip/slide trim
   - lift/extract/3-point edit
   - speed-aware sourceIn math
   - split/trim edits preserve keyframe automation with boundary keyframes and clip-segment retiming
   - undo/redo 정책과 충돌 방지

3. preview 엔진
   - browser preview와 FFmpeg 출력 일치
   - Program Monitor는 active video/image layers를 opacity, blend mode, transform 기준으로 다중 합성
   - proxy preview
   - audio waveform cache
   - waveform-based silence removal
   - waveform-based beat marker/cut automation
   - drop-frame 표시
   - STT caption timing이 preview와 render burn-in에 동일하게 반영

4. render 엔진
   - persistent render queue
   - retry/cancel
   - selected export profile이 manifest, parity, render plan, direct render, queued render를 모두 구동
   - proxy review profile은 master profile과 동일한 timeline/render graph를 사용하되 빠른 H.264 low-bitrate preset으로 출력
   - 저장된 오래된 프로젝트에도 proxy/master/social export profile 기본값이 마이그레이션으로 보강
   - FFmpeg hardware encoder를 감지하고 지원되는 경우 자동 선택하며, 미지원/감지 실패 시 software encoder로 fallback
   - embedded video audio mix
   - linked/unlinked embedded audio detach/relink
   - clip speed render with video `setpts` and audio `atempo`
   - source range 3-point insert/overwrite supports separate visual and audio patch targets
   - linked V/A clips from patch edits are selected, moved, pasted, overwritten, duplicated, split, trimmed, slipped, rolled, and slid as sync-preserving groups
   - linked V/A range lift/extract preserves tail references, source math, and keyframe slices
   - loudness normalization through FFmpeg `loudnorm`
   - crossfade/dip/push/wipe transition duration, easing, direction 저장과 FFmpeg `xfade` 반영
   - track solo state affects Program Monitor preview and FFmpeg render with separate visual/audio domains
   - keyframe transform/opacity/audio render and Inspector add/update/delete controls
   - static Motion transform controls with preview/render parity
   - caption import, burn-in, sidecar export
   - supported effect filter render
   - color match temperature/tint와 smart reframe은 preview와 FFmpeg filter graph에 같이 반영
   - job snapshot을 로컬 개발 `.danbi/jobs`, Electron 패키지 `userData/jobs`에 저장하고 재시작 후 interrupted 상태를 표시
   - 프로젝트 패키지는 asset 원본 바이너리를 포함하지 않더라도 경로 manifest와 재import 경고를 보존

5. automation/ComfyUI
   - 기본 편집기가 안정화된 뒤 연결
   - `/api/editor/hooks`로 editor event payload 준비
   - `/api/editor/automation`으로 selected clip automation plan 생성
   - `/api/editor/comfyui-jobs`로 batch queue, dry-run payload, optional execution, cancel, retry, status polling 제공
   - workflow 결과 source/renderPath snapshot, 원본/결과 side-by-side review, `AI Results` 후보 트랙 ingest, undo 가능한 원본 clip replacement 제공
   - 결과 review UI는 prompt/model/workflow metadata, ffprobe media analysis, duration/resolution mismatch, cache/proxy/waveform readiness를 표시해야 한다.
   - prompt lineage/version compare는 source generation prompt/workflow/seed와 result snapshot을 changed/same/missing 상태로 비교해야 한다.
   - workflow preset registry와 clip-to-workflow binding UI는 preset 기본 parameters, project rule parameters, clip generation overrides 순서로 payload를 결정해야 한다.
   - AI B-roll gap fill은 단일 트랙 gap이 아니라 전체 visual coverage gap을 기준으로 draft clip을 만들고, 생성된 clip은 기존 ComfyUI batch payload 경로를 그대로 사용해야 한다.
   - AI transition morph는 FFmpeg 즉석 필터가 아니라 ComfyUI 생성 transition job으로 다루고, outgoing transition의 adjacent clip context와 duration을 payload에 포함해야 한다.
   - subject-tracking smart reframe은 start/mid/end focal path를 effect parameters에 저장하고 Program Monitor preview와 FFmpeg dynamic crop expression이 같은 보간 규칙을 사용해야 한다.

6. STT 자막
   - 선택한 audio/video-audio clip을 queue job으로 처리
   - 로컬 STT 명령이 없으면 실패 사유와 설정 힌트를 노출
   - JSON/SRT/VTT/plain transcript parser 제공
   - clip `sourceIn`, speed, timeline start 기준으로 caption timing 보정
   - word-level timing이 있으면 caption metadata로 보존
   - 낮은 confidence, 짧은 duration, 과도한 읽기 속도, word timing drift를 검수 UI에서 선택하고 정리할 수 있어야 한다.
   - 결과 caption은 기존 caption edit/split/merge/style/burn-in/export workflow에 들어가야 한다.

7. Electron 로컬 앱
   - file system, FFmpeg, ComfyUI, SQLite는 main process에서 관리
   - renderer는 UI 전용
   - preload/IPC로만 로컬 권한 노출
   - packaged Electron의 imports/cache/projects/packages/jobs/stt/autosave/renders/outputs/temp는 Electron `userData` 아래에만 저장
   - 개발 모드에서만 project root `.danbi` 사용
   - Program Files 또는 설치 디렉터리 내부 storage write 금지

## Shotcut 참고 기준

Shotcut은 GPLv3 오픈소스이므로 구조와 기능 설계는 참고할 수 있다. 코드를 직접 복사하면 라이선스 의무가 커질 수 있으므로 Danbi Studio의 코어 코드는 직접 구현한다. 참고 대상은 MLT/FFmpeg 사용 방식, 필터 노출 구조, 작업 큐, 저장 포맷 범위다.

- 외부 서비스가 꺼져 있으면 편집기 전체가 깨지는 구조
