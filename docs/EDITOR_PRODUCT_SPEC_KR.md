# Danbi Studio 편집기 제품 기준

> 문서 우선순위: 완성 판정, 단계 진행, 외부 소스 재사용 정책은 `EDITOR_COMPLETION_DEFINITION_KR.md`와 `THIRD_PARTY_SOURCE_REGISTER_KR.md`를 우선한다. 이 문서는 제품 세부 요구사항과 현재 구현 범위를 설명한다.

## 목표

Danbi Studio 편집기의 1차 목표는 CapCut, Shotcut, Filmora보다 기본 편집 흐름이 빠르고 정확한 로컬 영상 편집기다. AI, ComfyUI, 자동화 API는 기본 편집기를 대체하는 장식 기능이 아니라 타임라인 작업을 확장하는 보조 레이어로 붙인다.

## 제품 원칙

1. 일반 편집 기능이 먼저다.
   - 멀티트랙 타임라인, 컷, 트림, 이동, 복제, 리플 삭제가 안정적으로 동작해야 한다.
   - 소스/프로그램 모니터, In/Out, 3-point edit, slip/roll/slide 같은 기본 NLE 작업을 우선한다.
   - 자막, 마커, 전환, 키프레임, 효과는 미리보기와 내보내기 결과가 최대한 일치해야 한다.

2. AI 기능은 타임라인을 깨지 않는 확장이어야 한다.
   - 선택 클립을 ComfyUI 작업으로 변환할 수 있어야 한다.
   - 빈 구간, 내보내기 전 처리, 수동 실행 같은 이벤트에서 자동화 payload를 만들 수 있어야 한다.
   - 기본 편집 UI가 불안정해지는 방식으로 AI 버튼을 앞세우지 않는다.

3. 로컬 우선 구조를 유지한다.
   - 원본 미디어와 프로젝트는 사용자의 로컬 파일 시스템과 로컬 DB에 남는다.
   - FFmpeg, ComfyUI, SQLite, 로컬 job snapshot을 기본 실행 기반으로 둔다.
   - 클라우드는 선택 기능으로만 고려한다.

4. 외부 도구와 연결 가능한 API 계약을 유지한다.
   - n8n, Make, 자체 스크립트가 사용할 수 있는 JSON payload를 안정적으로 유지한다.
   - UI, 렌더러, 자동화 API가 같은 `EditorProject` JSON을 해석해야 한다.

## 현재 구현 기준

- 편집 화면: `/editor`
- 프로젝트 모델: asset, track, clip, effect, keyframe, transition, caption, marker, plugin 선언, export profile
- 저장/불러오기: SQLite 기반 `/api/editor/projects`
- Optional cloud sync: Electron Project panel의 Sync folder는 사용자가 고른 로컬/클라우드 동기화 폴더에 portable project package와 manifest/index를 쓰며, 더 최신 원격 snapshot이 있으면 overwrite를 기본 차단한다.
- 미디어 import: `/api/editor/media`가 파일을 로컬 개발은 `.danbi/imports`, Electron 패키지는 `userData/imports`에 저장하고 preview/render 공용 `/imports/...` 경로를 만든다.
- Import routing: 일반 Import/Media Bin drop/native import는 video/audio/image media와 `.srt/.vtt` caption sidecar를 구분한다. Sidecar는 Media Bin asset으로 오인하지 않고 caption import workflow로 들어간다.
- 미디어 분석: `ffprobe`로 duration, display resolution, coded resolution, sample/display aspect ratio, video rotation metadata, JPEG EXIF image orientation, FPS, codec, audio metadata를 프로젝트 asset에 반영한다.
- 미디어 캐시/STT 부산물: thumbnail, preview proxy, waveform peak를 background queue로 생성하고 로컬 개발은 `.danbi/cache`, Electron 패키지는 `userData/cache`에 저장한다. STT transcript/encoder 작업 파일은 로컬 개발 `.danbi/stt`, Electron 패키지 `userData/stt`에 저장하며 job snapshot도 로컬 개발 `.danbi/jobs`, Electron 패키지 `userData/jobs`에 저장한다.
- 미디어 import e2e: Playwright smoke가 audio/video/image 임시 파일 10개를 한 번에 가져오고 Media Bin과 Command Palette가 계속 반응하는지 확인한다.
- Media Bin 관리: search, type/smart/bin filter, name/type/duration/usage-count sort, used/unused 상태 표시, remove unused, source/cache/relink/delete/insert/overwrite 액션을 제공한다.
- 타임라인 편집: split, move, trim, duplicate, delete, ripple delete, delete range, paste, ripple paste, overwrite paste, source range insert/overwrite, V/A source patch targeting, linked range lift/extract
- 타임라인 장편 성능: scroll viewport와 zoom 기준 visible clip render window를 계산해 긴 프로젝트에서 화면 밖 timeline clip DOM 렌더링을 줄이고, 선택 clip은 viewport 밖이어도 edit state를 유지한다.
- 소스 패치 워크플로: Source panel에서 현재 소스 asset의 V/A patch 대상 트랙을 직접 선택할 수 있고, 잠긴 트랙은 후보에는 표시하되 선택을 막는다. Source Monitor의 3-point insert/overwrite는 이 대상 트랙과 source In/Out을 사용한다.
- Source Monitor range rail: Source Monitor 안에서 I/O 핸들을 직접 드래그해 source In/Out을 프레임 단위로 조정하고, 핸들이 서로 넘어가 source range가 무너지는 상황을 최소 1프레임 길이로 방지한다.
- 정밀 편집: source/program monitor, source In/Out, JKL/shuttle, In/Out mark, lift/extract, 3-point edit, slip/roll/slide
- Precision Trim panel: Inspector에서 step frame 값을 1~600프레임으로 지정해 slip, roll, slide, J/L-cut audio split edit를 같은 단위로 적용할 수 있다.
- 선택/조작: multi-select, box select, group drag, Alt+Arrow nudge, context menu, expanded keyboard map
- 트랙/클립: mute/solo/lock, clip volume multiplier and dB gain editing, audio track gain/pan mixer, embedded video audio detach/relink, linked V/A selection/move/delete/paste/overwrite/duplicate/split/trim/slip/roll/slide sync, speed-aware source math
- 마커/자막: marker edit/jump, caption add/update/delete, draft, split/merge, SRT/WebVTT import/export, manual line break preservation, caption style controls(font/color/box/shadow/position/align)
- 로컬 STT 자막: 선택한 audio/video-audio clip을 로컬 Whisper 호환 명령으로 queue 처리하고 결과 transcript와 word-level timing을 편집 가능한 caption으로 가져온다.
- STT 자막 검수: 낮은 confidence, 짧거나 긴 duration, 과도한 읽기 속도, caption 범위 밖/겹침/역순 word timing drift를 UI에서 확인하고 문제 자막 선택/자동 정리/짧은 줄 병합을 수행한다.
- Project JSON schema: caption word-level timing은 배열 여부뿐 아니라 word start/end/text/confidence, caption range 포함 여부, 단어 순서와 겹침 여부까지 검증하고, caption style과 title-style effect는 font size/color/box/shadow/position/align 범위를 검증한다. Clip effect는 id/type/label/enabled/parameters 공통 계약을 검증한다. Automation rule, plugin manifest, export profile도 provider/trigger/permission/contribution/container/codec/bitrate 같은 실행 계약을 검증해 깨진 STT word data, 렌더 불가능한 자막/타이틀 스타일, 손상된 effect/automation/plugin/export payload가 저장/로드 경계에서 정상 프로젝트로 통과하지 않게 한다.
- STT speaker diarization draft: speaker가 비어 있는 STT/caption 구간에 주변 speaker label과 시간 간격 기반 draft label을 적용하고 speaker turn timeline을 검토한다.
- 오디오 자동 편집: waveform 기반 silence analysis/removal, beat detection, beat marker, selected clip beat cut
- 미리보기: program monitor preview stack, track order, mute/solo/lock state, opacity, blend mode, multi-line text/caption layout, text/caption shadow와 background box, effect/keyframe overlay, linear/ease in/ease out/ease in-out keyframe interpolation, source-range-aware timeline waveform and easing-aware volume envelope display for audio and embedded-audio video clips, easing-aware visual opacity envelope display for video/image/text clips, program audio meter peak/headroom/clipping readout
- 렌더 계획: `/api/editor/render-plan`이 FFmpeg command plan, warning, issue를 생성한다.
- 실제 렌더: `/api/editor/render`가 사용자가 지정한 파일 경로로 FFmpeg 결과를 저장하고, 지정 경로가 없으면 로컬 개발은 `.danbi/outputs`, Electron 패키지는 `userData/outputs`에 저장한 뒤 `/outputs/...` 링크를 반환한다.
- 렌더 큐: `/api/editor/render-jobs`가 progress polling, cancel, retry, priority, concurrency, persistent snapshot을 제공한다.
- 작업 이력: Export workspace는 render job list와 현재 media-cache, ComfyUI, STT job을 하나의 Job History dashboard로 합쳐 active/failed/completed/cancelled 상태를 보여준다. 실패한 FFmpeg job은 진단 category, 주요 조치, retry 가능 여부를 같이 표시한다.
- Render worker handoff: headless CLI는 `--handoff <path>`로 local network render worker용 manifest를 생성한다. Manifest에는 project summary, profile별 output path, preflight, FFmpeg command, extension hook snapshot, worker CLI command가 포함된다.
- Render worker runner: `npm run editor:render-worker -- --manifest <handoff.json>`는 handoff를 읽어 blocked job 보호, selected job dry-run/실행, JSON report 생성을 수행한다. 이 경계는 `third_party/source-mirrors`를 runtime import나 bundle 입력으로 사용하지 않는다.
- Render worker daemon: `npm run editor:render-worker-daemon`는 local HTTP endpoint를 열고 `GET /health`, `GET /status`, `POST /runs`, `GET /runs/:id`, `GET /runs/:id/events`, WebSocket `/events`로 handoff 제출, run report 조회, SSE progress streaming, daemon-wide fleet status streaming을 제공한다. `--max-runs`와 run lease metadata로 제출 run을 capacity 안에서 queued/running으로 관리한다. 이 daemon은 Danbi runner를 감싸며 `third_party/source-mirrors`를 runtime import나 bundle 입력으로 사용하지 않는다.
- Render worker controller UI: Export workspace에서 daemon/fleet discovery, manual remote daemon URL enrollment, worker selection, daemon URL/cwd/executable/dry-run/blocked/auto-route 옵션을 설정하고, 현재 프로젝트를 portable package로 export한 뒤 선택된 export profile handoff를 최신 fleet status 기준 least-loaded discovered/enrolled daemon에 제출하고 WebSocket fleet status stream, SSE progress stream, polling fallback으로 run report, job-level progress snapshot, running/queued/capacity, lease 상태를 갱신한다.
- 외부 소스 라이선스 경계: OpenCut/OpenCut Classic/Shotcut local mirror는 `third_party/source-mirrors.lock.json`에 origin, audit commit, license file, allowed use, distribution boundary를 고정하고, `npm run license:check`가 mirror ignore, NOTICE/register, MIT adapted-source header, Shotcut/GPL runtime source 차단을 검사한다.
- 렌더 진단: 실패 category, retry 가능 여부, 주요 조치 힌트, Resolve 버튼, evidence, stderr tail을 Render Status와 Job History에 표시한다. Browser-only source는 plan warning뿐 아니라 FFmpeg input source에서도 감지해 unsupported-source로 분류한다. Missing media Resolve는 evidence/stderr에 나온 input path를 우선 매칭해 해당 asset relink로 연결하고, 그 외에는 media relink, H.264/MP4 profile 전환, 새 output 선택/렌더, retry 흐름으로 연결된다.
- 출력 경로 preflight: 선택한 render output path가 비어 있거나 디렉터리이거나 확장자가 없거나 export profile container와 확장자가 다르거나 OS 파일 시스템 접근성 검사를 통과하지 못하면 queue/direct/headless render 전에 blocked issue로 표시한다.
- Export profile preflight: 선택한 export profile의 container/codec 조합이 FFmpeg mux 호환 allowlist에 없으면 queue/direct/headless render 전에 blocked issue로 표시하고 profile review 액션으로 연결한다.
- Export profile dimension preflight: profile 편집 UI/helper는 홀수 width/height를 가장 가까운 짝수 해상도로 정규화하고, 외부 반입/저장 JSON에 남은 홀수 export dimension은 schema validation과 render preflight에서 blocked issue로 차단한다.
- Caption preflight: caption timing이 비정상이면 blocked issue로 차단하고, 빈 자막/겹치는 자막/프로젝트 끝을 넘는 자막은 review warning으로 표시해 burn-in export 전에 수정할 수 있게 한다.
- Preflight Resolve: Export panel의 preflight issue는 actionKind별 primary Resolve 버튼을 제공한다. Resolve는 cache build, media relink, output 선택/렌더, profile 검토, preview/render review, timeline focus/review 흐름으로 연결된다.
- Implementation note 2026-06-17: Compact issue lists in Export Preflight, Preview/Render Parity, and Media Health panels now use a shared renderer helper that preserves the top actionable rows while showing the hidden issue count, so dense project states do not silently hide remaining warnings or blockers.
- Implementation note 2026-06-17: Command Palette search state now tracks total matches, visible capped rows, hidden row count, and a hidden-result label. The renderer surfaces the total result count and hidden command count so compact search results do not imply that the displayed rows are the full registry match set.
- FFmpeg encoder 감지: `/api/editor/ffmpeg-capabilities`가 encoder 목록을 감지하고 render plan/job은 hardware encoder를 자동 선택하거나 software로 fallback한다.
- Proxy render preset: `Proxy Review 540p` H.264 저비트레이트/veryfast/CRF profile을 제공해 긴 프로젝트의 빠른 검수 출력을 만든다.
- 렌더 지원 범위: track mute/solo/lock, black gaps, timeline start offset, audio delay/mix, embedded audio, clip speed, loudnorm, xfade, blend mode, text burn-in(multi-line/shadow/box), caption burn-in(font/color/manual line breaks/shadow/box/position/align), transform/opacity/audio keyframes
- Export profile 호환성: MP4는 H.264/H.265/AV1, MOV는 H.264/H.265/ProRes, WebM은 AV1 조합만 허용하고, WebM 렌더는 container 호환을 위해 Opus audio encoder를 사용한다.
- 효과 렌더: text slide motion, static audio gain, audio cleanup presets, side-chain ducking, crop mask, tracked object mask, smart reframe, stabilize/deshake, Visual FX presets including privacy blur, green-screen chroma key, soft glow, advanced bloom, motion trails, optical-flow motion blur, and film grain, local AI enhancement presets, ComfyUI/model-backed AI effect passes, color eq/curves/lut3d, color match temperature/tint
- 내보내기 profile: manifest, parity, render plan, direct render, render queue가 선택 profile을 공유한다.
- Marked range preflight: preview/render parity sampler는 선택 export range 안의 시간만 검사해 range 밖 browser-only media나 cache/render issue가 현재 export를 잘못 차단하지 않으며, 같은 문제가 range 안에 들어오면 blocked issue로 표시한다. AI model-pass가 FFmpeg에서는 렌더되지만 Program Monitor에서 private filesystem-only pass path를 preview할 수 없는 경우는 Export Preflight warning으로 표시한다.
- Implementation note 2026-06-17: Preview/render parity warnings for browser-only sources, unsupported enabled effects, effect layers, and AI model-pass preview gaps are owned by the export-graph feature matrix. Sample-time preview scans now keep Program Preview warnings only, so the same unsupported effect appears once in PreviewRenderParity and render preflight instead of as duplicated matrix/sample warnings.
- 큐 설정: `/api/editor/queue-settings`와 편집기 UI에서 render/cache/ComfyUI worker concurrency와 기본 priority를 제어한다.
- 자동화 hook: `/api/editor/hooks`가 `manual`, `on-import`, `before-export`, `on-gap` 이벤트를 local action summary, ComfyUI job, generate payload, webhook payload로 준비한다.
- ComfyUI 배치 큐: `/api/editor/comfyui-jobs`가 선택 클립을 batch job으로 만들고 dry-run payload 준비, 실제 ComfyUI `/prompt` 실행 옵션, cancel, retry, status polling, persistent snapshot을 제공한다.
- ComfyUI 결과 검수/반영: 실제 실행 결과의 public source와 FFmpeg renderPath를 job snapshot에 기록하고, prompt/model/workflow metadata, prompt lineage/version compare, ffprobe media analysis, cache/waveform readiness, duration/resolution mismatch를 표시한다. 원본 clip과 결과를 side-by-side로 비교한 뒤 `AI Results` 후보 트랙으로 가져오거나 undo 가능한 원본 clip 교체로 확정할 수 있다.
- ComfyUI workflow preset/binding: Inspector에서 선택 clip의 preset, workflowName, prompt, negative prompt, seed, steps, CFG, width, height를 수정하고 automation payload에 clip별 override로 반영한다. Plugin manifest가 `workflow` contribution과 `comfyui` permission으로 `comfyUIWorkflows`를 선언하면 built-in preset과 같은 목록에 표시되고, `plugin:<pluginId>:<presetId>` id로 clip binding과 automation payload에 plugin source/required node metadata를 보존한다.
- AI B-roll gap fill: non-audio 트랙의 visual coverage를 병합해 실제 빈 화면 구간을 찾고, `AI Fill` 액션으로 `AI B-roll` 트랙에 ComfyUI draft clip을 생성한다.
- AI transition morph: outgoing transition type으로 `ai-morph`를 적용하면 adjacent clip context와 transition duration이 포함된 `transition-morph` ComfyUI payload를 생성한다.
- subject-tracking smart reframe: 선택 visual clip에 start/mid/end focal path를 생성하고 Program Monitor preview와 FFmpeg crop expression이 같은 보간 값을 사용한다.

## 아직 필요한 고급 작업

- WebCodecs 기반 고속 preview worker. 현재 worker capability/budget telemetry, requestVideoFrameCallback 기반 실제 Program Monitor video frame telemetry, still image delivery, video source/video-thumbnail timestamp-aware frame request, cached thumbnail/ImageBitmap frame delivery, QuickTime-compatible MP4/MOV/M4V/QT extension routing, progressive MP4/H.264 avc1/avc3 CTTS/edit-list timing, compact `stz2` sample-size table, 64-bit `co64` chunk offset table, `mdhd`/`mvhd`/`stsd`/`stsz`/`stz2`/`stts`/`ctts`/`stss`/`stsc` truncation/range guard 및 MP4 orientation metadata, FFmpeg fragmented MP4/H.264 CTTS/edit-list timing, `tfhd`/`tfdt`/`trun` truncation/range guard 및 MP4 orientation metadata, MP4/H.265 HEVC, MP4/AV1 av01, MP4/VP8/VP9 vp08/vp09, WebM/VP8, WebM/VP9, WebM/AV1, Xiph/fixed/EBML laced WebM/VP8 worker decode attempt, WebM SimpleBlock/lacing truncation/range guard 및 cached-thumbnail fallback, 정지/스크럽 상태의 matching decoded worker frame 표시가 구현되어 있고, 남은 고급 작업은 더 복잡한 MP4/WebM 변형과 브라우저가 노출하는 추가 codec/profile 지원이다.
- 더 많은 FFmpeg AI/effect filter graph. 현재 local AI enhancement, Visual FX soft glow/advanced bloom/motion trails/optical-flow motion blur/film grain, ComfyUI/model-backed effect pass render graph, Danbi-owned model-pass preset/control layer는 구현되어 있고, 남은 고급 작업은 실제 built-in model binary/license 배포 또는 추가 특수 필터가 필요해질 때의 확장이다.
- STT acoustic embedding extraction. Optional `speakerEmbedding` import/schema/clustering, similarity threshold/margin review, ambiguous/low-similarity warning, and UI embedding review counts are implemented. The local STT/audio pipeline preserves transcript-provided embeddings, can call an external speaker encoder command through `DANBI_STT_SPEAKER_ENCODER_COMMAND`, auto-discovers packaged speaker encoder preset manifests from trusted Electron resources, and generates waveform-backed acoustic feature embeddings from caption source ranges when transcript/model embeddings are missing. Queueing STT captions applies available runtime waveform peaks, including parent runtime peaks for subclips, before building STT tasks so embeddings are not lost while cache persistence is still pending. Remaining advanced work is actual voiceprint model binary/licensing distribution only if Danbi ships a specific bundled model.
