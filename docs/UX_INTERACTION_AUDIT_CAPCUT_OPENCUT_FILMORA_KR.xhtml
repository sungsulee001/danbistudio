Danbi Studio Editor 상호작용 감사

CapCut, OpenCut, Filmora 계열 편집기 기준으로 기능 존재 여부가 아니라 사용자가 마우스로 직접 조작 가능한지를 평가했다.

Date: 2026-06-19 Scope: Editor interaction audit No code changes Browser DOM smoke used

핵심 결론: Timeline 쪽 직접 조작은 상용 편집기 기준에 꽤 가깝다. Program Monitor는 기능은 있으나 조건부 노출이며, 특히 scale/rotate handle은 노출은 되지만 실제 드래그 검증에서 변화가 없어 release UX 관점에서 blocker 후보이다.

판정 기준

  • 구현됨: 실제 화면에서 마우스로 조작 가능하고 상태 변화가 확인됨.
  • 부분 구현: UI 또는 로직은 있으나 조건부 노출, 일부 동작 실패, 또는 상용 편집기 기대치에 미달.
  • 미구현: 직접 조작 UI 또는 동작이 없음.
  • 구현됐지만 UI 노출 안 됨: 코드상 구현은 있으나 일반 사용 경로에서 보이지 않음.

상호작용 감사 결과

항목 판정 실제 사용 기준 평가
1. Program Monitor direct manipulation 부분 구현 위치 이동은 된다. 단, 기본 선택 클립 또는 keyframe 클립에서는 transform overlay가 안 뜬다. keyframe 없는 visual clip 구간에서는 overlay가 노출된다.
2. Clip edge trim interaction 구현됨 Timeline clip 좌우 edge drag로 trim 가능하다. Playwright에서 clip width 변경을 확인했다.
3. Clip move interaction 구현됨 Clip body drag로 timeline 이동 가능하다. Playwright에서 clip left 값 변경을 확인했다.
4. Timeline zoom interaction 구현됨 Timeline Zoom range slider를 마우스로 드래그할 수 있다. 12 -> 42 변경을 확인했다.
5. Timeline scrub interaction 구현됨 Ruler scrubber를 직접 드래그할 수 있다. 0 -> 12.5, 35 이동을 확인했다.
6. Playhead interaction 구현됨 Playhead range와 ruler scrubber 둘 다 있다.
7. Multi-select interaction 구현됨 Lane drag box selection 가능하다. 실제로 1개 선택 상태에서 2개 clip 선택으로 변경되는 것을 확인했다.
8. Drag/drop interaction 구현됨 Media Bin asset card는 draggable이고, timeline lane에는 dragOver, drop 구현이 있다.
9. Transform handles 부분 구현 Keyframe 없는 visual clip에서는 move, scale, rotate, crop handle이 노출된다. 다만 실제 smoke에서 move는 동작했지만 scale/rotate drag는 변화 확인에 실패했다.
10. Context actions 구현됨 Timeline clip 우클릭 context menu 노출을 확인했다. Trim, Delete, Group, Audio, Transition 계열 액션이 있다.

CapCut 기준 세부 평가

기준 판정 확인 내용
1. 영상 클릭 후 transform handles 존재? 부분 구현 기본 0초 Founder intro는 keyframe 때문에 없다. 35초 Workflow demo는 transform overlay 1개, rotate 1개, scale 4개를 확인했다.
2. 마우스로 위치 이동 가능? 구현됨 Program Monitor overlay drag 후 transform translate 변경을 확인했다.
3. 마우스로 크기 조절 가능? 부분 구현 Scale handle은 노출되지만 Playwright 실제 drag에서 크기 변경 확인에 실패했다.
4. 회전 핸들 존재? 부분 구현 Rotate handle은 노출된다. 다만 drag 변화 확인에 실패했다.
5. clip edge drag trim 가능? 구현됨 Timeline clip edge drag 후 width 변경을 확인했다.
6. clip drag move 가능? 구현됨 Timeline clip body drag 후 left 변경을 확인했다.
7. timeline zoom drag 가능? 구현됨 Zoom slider drag 변경을 확인했다.
8. scrub 반응성? 구현됨 Ruler drag 시 즉시 aria/value 변경을 확인했다.
9. preview 즉시 갱신? 부분 구현 Program Monitor direct move는 draft로 즉시 반영된다. Timeline move/trim은 timeline preview guide 중심이고 Program Monitor live preview까지는 제한적이다.
10. waveform interaction? 미구현 Waveform은 표시 전용이다. pointer-events-none이라 waveform 자체 드래그/편집은 불가능하다.

Release UX blocker 후보

  • 기본 진입 상태에서 Program Monitor transform handle이 보이지 않는다. 기본 선택이 clip-ai-city이고, 이 clip은 아직 생성 asset이 없는 kind: ai clip이다.
  • 기본 0초 visual clip인 Founder intro도 scale keyframe이 있어 transform overlay가 막힌다.
  • Keyframe 없는 visual clip에서는 overlay가 뜨지만 scale/rotate drag smoke에서 실제 변화가 확인되지 않았다.
  • Waveform은 표시 전용이라 CapCut식 waveform 직접 편집 기대치에는 미달한다.

이 문서는 상호작용 감사 보고만 기록한다. ComfyUI, Automation hooks, Render Worker, Plugin/Extension, export validation semantics는 변경하지 않았다.
