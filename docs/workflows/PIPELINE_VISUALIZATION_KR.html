주황 배지는 인간 승인 게이트 — 에이전트가 절대 스스로 넘지 않는 지점(Danbi의 dry-run 철학과 동일). 각 단계의 산출물은 Obsidian vault 마크다운 문서이며, frontmatter status가 다음 단계를 여는 열쇠다.

draft→ approved→ generated→ edited→ published vault 문서의 status 상태 머신이 곧 파이프라인 게이트. draft→approved 전이는 오직 인간만 수행한다.

GAP ANALYSIS

새로 만들 것은 4가지뿐 [사실]

편집·렌더·큐·보안 경계·상호교환은 이미 완성돼 있다. 집중 분석이 확인한 실제 결손:

① 콘티→프로젝트 컴파일러

콘티(컷 목록)→검증된 EditorProject JSON 생성기. 타임라인 함수는 순수 라이브러리로 이미 존재 — 조립만 하면 됨.

Phase 1 · 신규 개발 1순위
② 진짜 I2V 영상 워크플로우

현재 broll_i2v.json은 이름과 달리 SD1.5 정지 이미지용 플레이스홀더. WAN 2.1 API-format JSON 제작·등록 필요.

Phase 2
③ TTS 음성 생성

STT(음성→자막)는 강력하나 대본→음성 경로 전무. CosyVoice 3.0(한국어·클로닝) + SenseVoice 정렬로 채움.

Phase 2
④ 업로드 모듈

플랫폼 업로드 기능·계획 모두 없음(의도적 범위 제외). Danbi 밖 별도 프로세스로 신규 개발.

Phase 4
DECISION

"헤르메스 에이전트 필요?" — 지금은 아니다

✅ 결론: 1단계(반자동)에서는 기존 Claude Code 스킬 체계로 충분. 완전 무인화(2단계) 시점에 상시 데몬 오케스트레이터 1순위 후보로 재검토. 그때도 Danbi와는 CLI/MCP/파일 프로토콜로 느슨하게 연결.
