**계약 조정 사항** (해당 문서에 반영 필요 — 후속 작업):
| 항목 | 기존(쇼츠 전제) | 변경 |
|---|---|---|
| target_duration | 45~60초 | **300~600초** — S2 분량·검증 게이트 재계산 |
| 대본 형식 | 나레이션(N01) 단일 | **나레이션 + 캐릭터 대사** — 대사 ID 규약과 캐릭터 시트 신설 |

| 산출물 | 영상 1개 | **영상(유튜브) + 오디오(팟캐스트)** — 동일 타임라인에서 export profile 2개 [사실 — 프로파일 체계 지원] |
| 챕터 마커 | 부가 | 핵심 기능으로 승격(5~10분) |
| 업로드 | Shorts | 일반 영상(쿼터 동일) + 팟캐스트 RSS는 후속 단계 |
| 고증 | — | 시나리오에 "사실/각색 구분" 노트 추가 — 위키 페이지가 근거 출처 |
