INTERACTION RULES

게이트 인터랙션 규약 (전 화면 통일)

승인 버튼 위치·모양 통일

우측 패널 최상단 고정, 초록+자물쇠. 비활성 사유를 버튼 아래 한 줄로 항상 표기("미검토 컷 3개").

승인은 되돌리지 않는다

확인 다이얼로그(후속 자동 동작 명시) → status 전이 → log.md 기록. 재작업은 revise 코멘트로 — 상태 머신 역행 금지.

반려 = 사유 필수

사유는 %%revise%% 코멘트로 문서에 기록되어 그대로 에이전트의 재작성 입력이 된다.

EXTERNAL_PENDING은 버튼이 아니다

회색 배지 + 남은 절차 툴팁. 앱 안에서 할 수 있는 일이 없음을 명확히 표시.

실패는 홈으로 승격

빨강 카드에는 항상 "다음 행동" 1개를 제시 — 재시도 / 문서 열기 / 로그 보기.

UI의 쓰기는 3종뿐

status 전이 · revise 코멘트 · 트리거 요청. 이 원칙이 올인원(A안)으로 미끄러지는 것을 막는 가드레일.
