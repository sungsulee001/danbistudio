# 에디터 메뉴 한국어 언어 설정 반영

## 목적

설정 화면에서 메뉴 언어를 한국어로 선택했을 때 앱 셸, 에디터 상단 툴바, 타임라인 편집 메뉴, 에디터 주요 패널이 같은 언어 설정을 사용하도록 연결한다.

## 적용 범위

- 설정 > 메뉴 언어 카드 추가
- 공통 저장 키: `danbi.shell.language`
- 지원 언어: `en`, `ko`
- 앱 셸 메뉴: 파일, 편집, 클립, 타임라인, AI, 자동화, 렌더, 보기, 도움말
- 에디터 상단 메뉴: 편집, 생성, 라이브러리, 설정
- 에디터 상단 툴바: 가져오기, 명령, 내보내기, 렌더, AI 메뉴 등
- 타임라인 툴바: 실행 취소, 다시 실행, 자르기, Q/W 트림, 삭제, 리플, 스냅, 반복, 줌, 썸네일, 파형, 높이 등
- 에디터 좌측 영역: 기본 모드, 에셋 보관함, 미디어 검색/필터/정렬, 미디어 카드 액션, 공유 라이브러리 헤더
- 모니터 영역: 편집 작업공간, 프로그램/소스 전환, 소스 모니터 버튼, 프로그램 모니터 빈 상태
- 인스펙터 영역: 도크 탭, 변형, 전환, 키프레임, 명령, 클립/소스 미디어, 비주얼/오디오 페이드, 파형 싱크
- 타임라인 트랙: 트랙 메뉴, 패치/잠금/음소거/솔로 툴팁, 오디오 믹서
- 상태 패널: Scene readout, Media Health, Asset Health, Cache Job 표시

## 동작 방식

- `src/lib/editor/menu-language.ts`에서 언어 저장/읽기/구독을 담당한다.
- `src/electron/renderer/use-menu-language.ts`에서 에디터 렌더러 컴포넌트가 공통 언어 상태를 구독한다.
- 설정 화면과 앱 셸은 같은 저장 키를 사용한다.
- 같은 브라우저 세션에서 설정을 바꾸면 커스텀 이벤트로 에디터 메뉴 구독자가 갱신된다.
- 테스트 안정성을 위해 `data-testid`, `data-toolbar-group-label`, 내부 그룹 키는 영어 식별자를 유지한다.
- 프로젝트 데이터인 클립명, 파일명, 프리셋명, 사용자 입력 프롬프트, 경고 원문은 자동 번역하지 않는다.

## 제외 사항

- 편집 기능 동작 변경 없음
- ComfyUI 통합, ComfyUI 배치 큐, AI Results, 자동화 훅, Render Worker, 플러그인/확장 시스템 변경 없음
- 렌더/익스포트 검증 semantics 변경 없음

## 확인 기준

- 설정 화면에서 `한국어` 선택 가능
- `/editor` 이동 후 상단 메뉴, 타임라인 메뉴, 에셋 보관함, 편집 작업공간, 인스펙터 주요 패널이 한국어로 표시
- 기존 영어 식별자 기반 E2E 선택자는 유지
- 관련 E2E: `editor-control-surface-audit.spec.ts`의 `applies Korean menu language to editor and timeline menus`
