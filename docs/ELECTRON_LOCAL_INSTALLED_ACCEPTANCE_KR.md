## Local Installed-App Acceptance

The current agent task is complete when Local Installed-App Acceptance passes on the local PC.

Required evidence:

- installer exists
- installed app launches
- project loads
- media import does not fail with `EPERM mkdir C:\Program Files\Danbi Studio\.danbi`
- packaged Electron writes `imports`, `cache`, `projects`, `packages`, `jobs`, `stt`, `autosave`, `renders`, `outputs`, and `temp` under Electron `app.getPath("userData")`, not Program Files
- packaged sample media resolves valid filesystem `renderPath` values for FFmpeg
- export preflight runs
- render executes
- output MP4 is produced and ffprobe-readable
- worktree is clean, or all changes are clearly reported

Commands:

```powershell
npm run electron:install-smoke
npm run electron:local-installed-acceptance
```

`electron:install-smoke` writes `.danbi/electron-install-smoke/result.json`.

`electron:local-installed-acceptance` reads the installed-app smoke result and writes `.danbi/electron-release/local-installed-acceptance.json`.

## Architecture Constraints

- ComfyUI integration
- ComfyUI batch queue

- Automation hooks
- Render Worker

- Fleet Discovery
- Headless Render
- Plugin / Extension system
- existing export validation semantics for ComfyUI generation

Fixes in this path are limited to discovered packaged Electron runtime bugs, storage paths, packaged sample media path rewriting, and the local installed-app acceptance criteria above.
